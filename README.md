# 🌳 شجرة العائلة

تطبيق ويب عربي لبناء شجرة العائلة وإدارتها، يعمل على GitHub Pages مع Firebase (مصادقة + قاعدة بيانات).

## المزايا

- **دخول بيوزر وباسورد** — أدمن أكبر (المالك) وأدمنية مصغّرون يضيفهم المالك.
- **سجل تعديلات** — يظهر مَن أضاف ومَن عدّل كل فرد، وسجل كامل بكل الأعمال.
- **الشجرة** من الآباء المؤسسين نزولاً للأبناء والأحفاد:
  - الذكور بالأزرق، الإناث بالوردي، الأزواج والزوجات من خارج العائلة بالأخضر.
  - المتوفى يحمل شريطاً أسود أعلى بطاقته.
- **بيانات الفرد**: الاسم، سنة الميلاد (هجري أو ميلادي مع تحويل تلقائي)، النوع، الحالة، سنة الوفاة، صورة اختيارية (تُضغط تلقائياً).
- **حساب القرابة** بين أي شخصين (عم، خال، ابن عم، حفيد… مع سلسلة النسب).
- **تصدير PDF** للشجرة كاملة أو لفرع شخص واحد، بتنسيق جميل للطباعة.
- **بحث** بالاسم، وتكبير/تصغير وسحب حر للشجرة.
- **وضع تجريبي** بلا حساب: أضف `?demo=1` للرابط (بيانات محلية في المتصفح فقط).

## الإعداد (مرة واحدة)

1. **Firebase Console** → مشروعك → **Authentication → Sign-in method** → فعّل **Email/Password**.
2. **Firestore → Rules** → الصق محتوى ملف `قواعد-فايرستور.txt` وانشر.
3. افتح الموقع → **⚙️ الإعداد الأول** → اكتب اسم العائلة واسم المستخدم وكلمة المرور → تصبح الأدمن الأكبر، وتُقفل البوابة تلقائياً بعدها.
4. من زر **👥 الأدمنية** أنشئ حسابات الأدمنية المصغّرين.

## البنية

| الملف | الوظيفة |
|---|---|
| `index.html` | كل الشاشات والنوافذ |
| `app.js` | المنطق: المصادقة، Firestore عبر REST (بلا SDK)، رسم الشجرة، القرابة، التصدير |
| `style.css` | التنسيق (خط صقال سعد مضمّن في `fonts/`) |
| `config.js` | معرّف مشروع Firebase ومفتاح الويب |
| `قواعد-فايرستور.txt` | قواعد الأمان — الكتابة للأدمنية المسجّلين فقط |

## ملاحظات أمنية

- مفتاح الويب في `config.js` عام بطبيعته؛ الحماية في قواعد فايرستور: لا قراءة ولا كتابة لبيانات الشجرة إلا لحساب موجود في `ft_users`، والحذف وإدارة الأدمنية للمالك فقط.
- بوابة «الإعداد الأول» تُقفل بإنشاء وثيقة `ft_meta/setup` مرة واحدة ولا يمكن تكرارها.
- تحويل السنوات هجري↔ميلادي تقريبٌ سنوي (±سنة).
